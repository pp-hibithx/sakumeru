卓準備

最後に開いたKPバインダー

SCENARIO

遊ぶシナリオをまとめる

所持・通過・予定・KP状況を、 自分用のシナリオ棚にまとめられます。

 CALENDAR

卓予定をまとめる

予定と遊んだ記録を、日付から確認できます。

 LIBRARY

セッション記録をまとめる

友達と遊んだ卓を、 ネタバレに配慮したアルバムとして残せます。

 PC

キャラクターをまとめる

PC紹介・キャラクターシート・参加シナリオ履歴をまとめます。

 PLAYERS

同卓者をまとめる

一緒に遊んだ人と、同卓したシナリオや履歴をまとめます。

 PROFILE

自己紹介をまとめる

卓の好みや遊び方をまとめて、必要な項目だけ共有できます。

 TOOLS

卓を少し便利に

ダイスログ解析などのWebツール。

 HELP

使い方を見る

やりたいことから、各機能の操作方法を確認できます。

 BACKUP

データを守る

SCENARIOとLIBRARYに保存したデータを、 書き出して保管できます。
