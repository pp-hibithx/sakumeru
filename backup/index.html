BACKUP

SAKU+MERUのブラウザ保存データを、まとめてバックアップ・復元します。

バックアップ対象一覧
  • SCENARIO
  • CALENDAR
  • LIBRARY
  • PC
  • PLAYERS
  • プロフィール
  • 卓準備
  • 記事
  • KPバインダー
  • 各種設定
  • ブラウザ内に保存した画像・音声
  • DISPLAY MAKERの一時保存

このバックアップは、SAKU+MERUに保存したデータを復元するためのものです。
端末のデータを消してしまった場合や、別のブラウザへ移すときに使用できます。
最終バックアップ：まだありません

クラウド同期

PCとスマホなど、同じ同期コードを使う端末間で主要データを同期できます。完全バックアップとは別の機能です。

ONにすると、対応ページの起動時にクラウドの新しいデータを確認し、編集後は自動保存します。詳しい同期状態はこの画面で確認できます。

✓ SCENARIO✓ CALENDAR✓ LIBRARY✓ PC✓ PLAYERS✓ HOME設定✓ WORK LOG端末ごと：稼働中タイマー／今ここ！

クラウド同期は複数端末で使う主要データ、完全バックアップは復旧用の包括的保存です。

同期コードを知っている端末だけがデータを読み込めます。公開しないでください。

⚠ 同期競合あり

この端末とクラウドで内容が異なります。残す内容を選んでください。選ぶまでどちらも上書きしません。
