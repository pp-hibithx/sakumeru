BACKUP

SAKU+MERUのブラウザ保存データを、まとめてバックアップ・復元します。

バックアップ対象一覧
  • SCENARIO
  • CALENDAR
  • LIBRARY
  • PC
  • PLAYERS
  • プロフィール
  • 卓準備
  • 記事
  • KPバインダー
  • 各種設定
  • ブラウザ内に保存した画像・音声
  • DISPLAY MAKERの一時保存

このバックアップは、SAKU+MERUに保存したデータを復元するためのものです。
端末のデータを消してしまった場合や、別のブラウザへ移すときに使用できます。
最終バックアップ：まだありません

クラウド同期

PCとスマホなど、同じ同期コードを使う端末間で主要データを同期できます。完全バックアップとは別の機能です。

ONにすると、起動時にクラウドの新しいデータを読み込み、編集後は自動保存します。画面右下に同期状態が表示されます。

同期コードを知っている端末だけがデータを読み込めます。公開しないでください。
