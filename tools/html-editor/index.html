使い方

  1. HTMLを開くで編集したいファイルを選びます。元ファイルは変更されません。
  2. 左側でHTML・CSS・JavaScriptを編集します。検索はCtrl+F、元に戻す／やり直すはCtrl+Z／Ctrl+Yです。
  3. 通常は安全プレビューで見た目を確認します。実データで確認するときは実データ・読取専用と元ページを選びます。このモードは公開したHTML EDITOR上でのみ使用できます。
  4. PC表示と390px表示を切り替えて確認します。
  5. 保存用HTMLを出力を押すと、編集後のHTMLが新しいダウンロードファイルになります。

どちらのモードもsandbox付きiframe内で動作し、外部通信を遮断します。実データモードは現在のLocalStorageをコピーして渡し、setItem／removeItem／clearを遮断します。sessionStorageは空、IndexedDBは利用不可です。
